# 🔴 Red Team Knowledge Sharing Repository

Welcome to this repository.

This repository is a **personal Red Team knowledge base** where I document and share tools, techniques, notes, and practical experiences that I learn during my cybersecurity journey.

The purpose is simple:

> Share useful Red Team knowledge in one structured place for learning and practice.

# 🎯 What This Repository Contains

This repository focuses on **practical Red Team knowledge**, including:

* reconnaissance techniques
* enumeration methodology
* privilege escalation notes
* active directory attack techniques
* post-exploitation workflows
* command cheat sheets
* useful scripts
* lab notes
* CTF-related knowledge
* tool usage examples

This is not a theoretical repository.

It is built mainly for **hands-on security learning and experimentation**.
